# 电脑难度

0.3.0 提供三档电脑策略，规则和发牌方式相同。默认标准；旧练习和旧服务端存档没有难度字段时也使用标准。

| 难度 | 出牌方式 |
| --- | --- |
| 轻松 | 优先最小的合法代表牌，保留直接出完和让队友先走的基本处理，适合熟悉操作 |
| 标准 | 保留 0.2.0 策略，兼顾一次出牌张数、级牌配牌、拆对子代价与对家配合 |
| 进阶 | 比较出牌后自己剩余的组合，尝试顺子优先和同点数组合优先两种有限分解，并考虑拦截与收尾 |

进阶是有界启发式，不是精确最优解。电脑只看自己的手牌、公开牌型、各席剩余张数与已完成名次，不读取其他手牌，也不调用外部模型。所有档位都会经过同一个规则裁判。

练习开始前可在首页选择；副间也可以调整。亲友桌只有房主可以在开局前或两副之间调整，所有客户端同步显示。一副中途保持当前难度，电脑队友、对手及代打都使用同一档。为了继续提供一致的候选牌，人的“提示”使用标准策略，不随电脑难度降低。

## 策略比较

使用固定种子 20000—20099，各副保持同一发牌并交换两边队伍的策略，每组 200 局，级牌和首出位置按种子变化：

| 两队策略 | 胜局 |
| --- | --- |
| 进阶 / 标准 | 132 / 68 |
| 标准 / 轻松 | 150 / 50 |

这些是程序互打结果，不是人类段位、真人胜率或每一副都更强的承诺。选轻松会同时改变电脑队友和对手，因此不保证人类玩家一定获胜。

可复验：

```sh
npm run build
node dist/tools/benchmark-ai.js advanced standard 100 20000
node dist/tools/benchmark-ai.js standard easy 100 20000
```

另以三档完整对局检查动作合法、108 张牌守恒，以及相同观测不被策略修改。Android 的解释器运行与 Node 的 54 份状态参考样例比较，并对三档分别完成一副、重开与继续。原生安装和联机证据见[验收记录](acceptance.md)；通用模拟器不代表华为 ROM 的实机验收。
