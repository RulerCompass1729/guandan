| 独审：等待桌最后一人离开后，新人按原桌号加入 | 中：房主空缺，无法开始 | 已关闭：HTTP修前失败，修后可开局 |
| 独审：建桌或入桌的保存单次失败后重试 | 高：可能确认未落盘的座位，重启后丢失 | 已关闭：先回滚再重试，重启恢复原座位；两路故障注入通过 |
| 独审：断线接管定时器恰遇保存失败 | 中：未捕获异常与控制权不一致 | 已关闭：回滚并延后重试，故障注入先不托管、随后持久化成功 |
| 独审：网站存储禁止读取或清理 | 中：加载停住或原错误说明丢失 | 已关闭：安全读取/清理，真实浏览器故障注入通过 |

## 环境与未验范围

服务实际运行于Node.js 26.12.1；浏览器自动化使用Playwright 1.65.0。Android使用四个独立API33 ARM64通用镜像、Chrome 109.0.5414.123、Emulator 36.4.10、Appium 3.9.0和UiAutomator2 8.7.3。镜像包含Google组件；业务源码无Google服务依赖不等于已验无Google系统。

- Mate 30在国内测试者手中，尚未完成实机系统浏览器、后台/锁屏、桌面入口、放大字号和长辈独立操作；下一步由测试负责人按[真机试用](phone-check.md)安排。
- 国内Wi-Fi/移动网络和公网HTTPS尚未验收，也尚未提供公网游戏服务；有获授权的部署目标后再部署并安排远程手机复验。
- 网页存储接口返回不保证浏览器已将新凭据写到磁盘。刚建桌后立即强制终止浏览器的首次凭据耐久性不在保证范围，服务端仍保留牌局；凭据丢失不会自动授予原座位。
- 当前电脑玩家为基于受限观测的规则策略，未做棋力排名或真人胜率承诺；尚不支持陌生人匹配和实时语音。

脚本操作人类席位不等于真人试用；通用Android不等于华为ROM，也不存在“100%拟真”的保证。测试原始证据保留在私有位置，公开仓库只放可复现代码和脱敏结论。
