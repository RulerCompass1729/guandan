# Mate 30真机试用

此项尚待真实设备验证。通用Android模拟器、相同屏幕尺寸或同名AVD均不能代替它。

## 开始前

由测试负责人提供获授权且可访问的游戏地址，并准备两部真实手机，其中一部为Mate 30。远程手机不能使用开发电脑的localhost地址。请记录本次游戏版本、手机系统名称与版本、浏览器名称与版本，以及使用Wi-Fi还是移动数据；不要仅记录“华为浏览器”。

## 一次完整任务

1. 用系统浏览器打开地址，填写称呼或留空，建一桌。
2. 把8位牌桌号告诉第二位玩家。第二部手机输入号码入座，确认双方看见同一张桌和正确的队友。
3. 两人先分别坐对面作为同队，再确认换座和另一队配置都能理解。点开始，空位由电脑补齐。
4. 检查27张牌能否看清、选错再点是否取消、提示是否可以拒绝。确认选牌本身不会立刻出牌，出牌按钮和不要按钮都能准确点到。
5. 共同打完一副，两边看到一致结算；继续下一副，检查升级和需要还牌时的说明。
6. 一部手机暂时断网，另一部保持正常。服务器确认离线并经过等待后应显示电脑代打；重新连接后回到原座位，点接回，不能重新发牌或多出一手。
7. 切到其他应用、锁屏后回来，以及刷新页面，确认仍是原牌桌。检查横竖屏、系统字号放大时，牌面和主要按钮不被遮住。
8. 从浏览器菜单尝试添加到桌面，再由本人独立从桌面回到原牌桌。菜单名称和是否支持以实际系统版本为准。

至少换一次Wi-Fi或移动数据重复加入与恢复。网络断开被检测到的时间、页面后台策略和桌面入口是本次真机重点，不从模拟器的结果推断。

## 记录结果

分别记录通过、失败、未测，附具体操作和可见结果。尤其记录需要旁人代操作的地方、误触、看不清和不知道下一步怎么做的地方。不要让开发者的熟练操作代替目标玩家体验。

真机原始录屏和日志留在私有位置；公开问题只放脱敏复现。完成这份检查前，不把Mate 30写成“已支持”。
