# Mate 30 原生 APK 试用

尚待真机验证。通用 Android 模拟器不能代替华为 ROM、真实触摸和长辈试用。

## 准备

测试负责人提供签名 APK、版本与 SHA256。至少两部 Android 手机，其中一部 Mate 30，记录系统、版本、字号和网络。实际安装 APK，由桌面图标启动，不使用浏览器快捷方式。

离线练习无需服务器。异地联机须有获授权、国内可达的 HTTPS 服务；远程手机不能使用开发电脑 localhost。组织者预填服务，或亲自完成一次设置，不让长辈填写技术参数。

## 完整任务

1. 安装并启动，先进入电脑练习；检查所有牌、主按钮和系统提示可见，没有浏览器引导。
2. 选牌、取消、提示，再确认出牌；选牌本身不能发出。切换大字和紧凑，展开牌组核对总数与全部花色。
3. 关闭再从桌面启动，确认排列选择和练习进度保留。
4. 联机后一部建桌，另一部输入八位桌号；核对桌号、座位、对家，换座后开始，空位电脑补齐。
5. 共同完成一副，核对一致结算并继续，检查升级和贡还说明。
6. 单端断网，另一端正常；经过等待后电脑代打。恢复原席并接回，不重新发牌或多出一手。
7. 切换应用、锁屏、关闭重开、Wi-Fi/移动数据切换后检查原桌。清应用数据会丢本机凭据，须单独告知。
8. 检查横竖屏和放大字号，主操作能看清、点到；让目标玩家第二次独立从桌面进入、入座、出牌和回桌。
