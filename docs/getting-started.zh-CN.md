# 新手上手

下载安装包后，打开“亲友掼蛋”。建议横着拿手机，牌能铺得更开。安装需要手机系统支持 Android APK；Mate 30 的实际系统版本和安装提示仍需在手机上确认。

1. 首页向上滑到“电脑难度”。第一次可选“轻松”，再点“确定”。点“取消”不会改动原来的选择。
2. 点“先和电脑练一局”。不用注册，也不用联网，另外三个位置由电脑补齐。
3. 下方是您的手牌，正对面是队友。看到“轮到你了”再操作。
4. 点牌选中，再点同一张可以取消。不知道出什么，可点“提示”。提示只选候选牌，看清以后还要点“确认出牌”。
5. 跟牌时不想跟或压不过，可以点“不要”。自己领出新的一手时，需要出牌。
6. 右上方“紧凑”和“大字”可以切换。紧凑排列先点牌组展开，选好以后仍需确认出牌。
7. 歇一会儿可点“代打”，回来点“接回”。临时关闭应用，重开会回到原来的练习；不要卸载或清除应用数据，以免删除进度。
8. 一副结束后点“继续下一副”。如果出现还牌提示，按提示选牌并确认。忘了规则，可点右上方“⋯”→“玩法说明”。

先记住三个按钮：**提示、确认出牌、不要**。可以暂停视频，再到应用里试一试。

亲友联机需要大家连接同一个可达的游戏服务。目前发布包可以离线练习，尚未提供国内公网游戏服务。APK 下载地址与游戏服务是两件事。
