# 本桌规则

规则版本：`gd-2022-home-v1`。以2022竞技掼蛋的牌型、升级和贡还规则为基线，配合下列线上亲友局约定。此实现不宣称得到赛事认证，也不实现裁判罚分、复式记分和线下抓牌程序。

依据：[2022规则公开转载](https://hy.lingti.com/rules/jingji-guandan-2022)、[东南大学赛事规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)。转载不是官方终稿；与亲友约定不同的地方应在开局前确认，不在中途静默改变。

- 四席、对家合作，两副牌108张，每席27张。座位按本家、右侧下家、对家、左侧上家递增，依次出牌。首副由服务端随机决定首出，后续由贡还规则决定。
- 大王、小王、级牌、A到2依次降低，同点不比较花色。红桃级牌可替大小王以外的牌；单独出时仍是级牌。连续牌型中的普通级牌按原点数排序。
- 单张、对子、三张、三带对、五张顺子、三连对、两连三张。A可位于连续牌型的最低端或最高端，不能绕接。三带对只比三张。
- 四张炸、五张炸、同花顺、六张及以上炸、四王依次增大；炸弹先比张数再比点数，不比花色。红桃配牌允许九张、十张炸。同一选牌有多种合法配牌解释时，界面列出解释，玩家确认后提交。
- 出完的一手未被压，其他在场玩家均过牌后，由本人或已出完者的搭档领出。三人出完或同队占前两名立即结算；双下两席不再强行排第三、第四。
- 头游的搭档为二游、三游、末游，分别升3、2、1级；升级最多先到A，必须实际打A。打A且本队已经到A，获得头游、搭档非末游才过A。
- 从第二副起，单贡由末游向头游贡最大合法牌，红桃级牌不进贡。原文未给同队首末单贡豁免，本桌不自行添加该豁免。双下两人都贡：头游收较大牌，对家收较小牌；同大时由头游下家贡给头游。贡给头游者先出。
- 单贡者或双贡双方合计抓到两张大王，抗贡，头游先出；单贡时不能借搭档的一张大王抗贡。
- 收贡者还一张不高于普通10的牌；若全手都更高，则还最小牌。级牌按其升级后的牌力判断。界面推荐最小合法还牌，玩家可选其他合法牌；电脑自动选择。两组贡牌先同时转移，再分别还牌，全部完成才开始出牌。
- 张数自动展示。电脑身份与代打状态可见；玩家可以托管和接回。没有强制短出牌倒计时。房主开局，空位补电脑；电脑空位可由后到的亲友加入，断线真人座位保留。

独立样例要覆盖花色相等、A2345、A23连对/A2钢板、配牌声明、四王与各炸弹边界、接风、双上即结束、贡还/抗贡和实际过A。随机自对弈不能代替这些样例。
